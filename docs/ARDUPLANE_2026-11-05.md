# Доводка ArduPlane — 5 ноября 2026

- Цикл MAVLink работает по монотонным часам даже при паузе Gazebo.
  HEARTBEAT — 1 Гц; для входящего UDP первый ответ возможен после того,
  как получен адрес партнера. ATTITUDE, RAW_IMU, SCALED_PRESSURE и
  LOCAL_POSITION_NED запрашиваются каждые 5 с при живом соединении.
- При включенной настройке SITL передаются SET_GPS_GLOBAL_ORIGIN и
  MAV_CMD_DO_SET_HOME (явная команда изменения Home, пока не armed).
  HOME_POSITION используется для отчета о Home, а не вместо команды.
  GPS1_TYPE/GPS2_TYPE отключены; реальной GNSS-позиции в ExternalNav нет.
- Для датчика, поставляющего исходные пиксельные смещения, одновременно
  включить send_integrated_flow и send_legacy_flow. OPTICAL_FLOW (100)
  берет flow_px_x/y из IntegratedOpticalFlow; он не восстанавливается
  из оцененной скорости. Нынешний узел камеры не публикует этот контракт.
  Схема ROS-сообщения изменилась: пересоберите и его отправителей.
- В мире ArduPlane старт корпуса на 145,25 м. На креплении барометр
  получает поправку по медиане 25 первых значений. Тарировку нельзя
  начинать в движении. Сдвиг оптического центра вниз на 0,25 м
  уже учитывается в optical_flow_node через матрицу ориентации.
- imu_camera_time_offset в секундах прибавляется ко времени поиска в
  буфере IMU: к середине и обеим границам интегрирования. По умолчанию 0;
  метки кадра, барометра и навигации остаются прежними. Ненулевой сдвиг
  требует измерения задержки; наличие параметра не доказывает снижение дрейфа.
