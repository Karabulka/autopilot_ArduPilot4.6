# Пояснительная записка: навигация планера без GPS
**Статус на 12 ноября 2026 года · результаты контрольного SITL-полета**

## 1. Что уже есть на руках

Работает стенд **ArduPlane 4.6.3 + Gazebo Harmonic + ROS 2 Jazzy**
с управляемым полетом в GUIDED и штатным армированием. GPS исключен
из контура: **GPS1_TYPE=0, GPS2_TYPE=0** — реализация требования
«GPS_TYPE=0» в этой версии. Подготовлены воспроизводимые патчи EKF3 без GPS
и транспорта SITL.

Разработан собственный конвейер на OpenCV: **Shi–Tomasi → cornerSubPix →
пирамидальный Lucas–Kanade → проверка треков вперед/назад → RANSAC →
взвешенный МНК с весами Хьюбера**. Реализованы компенсация вращения по
интегралу гироскопа за интервал кадра, наклона и рычага камеры; магнитный курс
с компенсацией крена/тангажа и склонения. Скорость интегрируется в локальной
системе ENU; LOS формирует уставки следования по точкам.

В Gazebo работает **glider_visual** с камерой **640×480, 30 Гц**, IMU,
магнитометром, барометром и аэродинамическими LiftDrag-системами.
Интерфейсы: **ROS 2 топики и MAVLink 2** — OPTICAL_FLOW,
VISION_SPEED_ESTIMATE, VISION_POSITION_ESTIMATE, SET_ATTITUDE_TARGET.
ArduPlane управляется через MAVLink; принятый сенсорный путь —
прямые ROS-потоки IMU и давления.

Дашборд отображает маршрут, видеопоток, счисление пути и эталон Gazebo,
**8 графиков наведения и точности**, сохраняет журналы сравнения.
Наложение векторов потока на видео пока не реализовано.
Эталон используется только оценщиком, не навигацией или наведением.

**Контроль: 90 секунд фактического полета; flight.passed=true,
accuracy.passed=true; 27/27 проверок colcon без ошибок и отказов.**

| Показатель | Измерено |
|---|---:|
| RMSE Vx / Vy в FLU; порог <0,5 м/с | **0,113 / 0,132 м/с** |
| RMSE барометрической высоты корпуса | **0,0075 м (7,5 мм)** |
| RMSE крена / тангажа ATTITUDE ArduPlane | **0,58° / 1,09°** |
| Возраст MAVLink IMU / давления: максимум | **12 / 12 мс** |
| Доставка прямого IMU / давления: максимум | **20 / 16 мс** |

Задержка около **1,25 с** устранена исправлением очереди UART SITL:
за тик отправляются все готовые MAVLink-фреймы в пределах бюджета байтов,
отдельными небольшими UDP-пакетами; приемник дренирует очередь.

**Ограничения.** Метрики достигнуты при INERTIAL_SOURCE=direct над плоской
текстурированной поверхностью, в штиль. Ориентация Gazebo IMU идеализирована;
миллиметровая высота не характеризует реальный барометр. INERTIAL_SOURCE=mavlink
сохранен для сравнения: остаточная фильтрация, фаза ATTITUDE и обратная связь
ExternalNav ухудшают точность; единственная причина остаточной ошибки не доказана.
Yaw ATTITUDE ArduPlane имеет RMSE около 4,35°; наш курс — магнитный.
Приемка 90 с не доказывает отсутствие длительного дрейфа, точность удержания
любого маршрута или готовность аппаратного борта. Максимумы доставки
измерены по /clock, не являются гарантией hard real-time.

Репозиторий: [github.com/Karabulka/autopilot_ArduPilot4.6](https://github.com/Karabulka/autopilot_ArduPilot4.6).
Основание: docs/results/acceptance_20261112.json и XML результатов colcon.

## 2. Статус выполнения поставленных задач

| Задача | Статус | Что сделано |
|---|---|---|
| Перевод на ArduPilot 4.6 | Подтверждено в SITL | Plane 4.6.3, EKF3 без GPS, патчи UART/FDM/часов; GUIDED и штатное армирование. |
| Изучение Optical Flow / OpenFlow | Обзор подготовлен | Сравнены подходы и вычислительный бюджет. OpenFlow как SDN-протокол к оптическому потоку не относится. |
| Optical Flow и точность | Приемка в идеальном SITL | Собственный конвейер; RMSE Vx/Vy 0,113/0,132 м/с. На аппаратуре не проверено. |
| Планер в Gazebo Harmonic | Интегрирован | glider_visual и датчики работают; реальные поляры еще не идентифицированы. |
| MAVLink + ROS 2 | Реализовано в SITL | Уставки, ExternalNav, поток, сенсоры, одометрия, дашборд; физический UART еще не испытан. |
| Вычислитель и авионика | Подобраны, не закуплены | Pi 5; Matek H743-WING V3 / Pixhawk 6C; OV9281 / IMX296, RM3100, Пито, питание, UART 921600 бод. |
| Дальномер и носитель | Есть BOM и компоновка | TFmini-S — ближний канал; SF20/C — кандидат для 30–60 м. Выбран Ranger 2400 757-9 PNP. |

glider_visual имеет размах **3,2 м** и суммарную массу **1,6 кг**;
Ranger — размах **2,4 м**. Текущий SDF **не является измеренным цифровым
двойником** носителя. Геометрия, масса, инерция, ЦМ и поляры реальной сборки
подлежат измерению.

## 3. План дальнейших действий

**Шаг 1 — усложнение симуляции.** Добавить ветер, переменный рельеф,
лазерный AGL и отказы измерений. Оценивать ветер/снос по вектору путевой
скорости, курсу и скорости Пито с допущением о боковом скольжении:
одна скалярная воздушная скорость угол сноса не определяет.
Уточнить аэродинамические поляры под выбранный носитель; повторить приемку.

**Шаг 2 — утверждение BOM и настольный стенд.** Собрать Pi 5 + Matek +
Global Shutter камеру; проверить питание, временные метки, UART MAVLink
921600 бод, FPS и задержки на ARM Cortex-A76. Затем подключить реальный
контроллер к симуляции для HITL; сама настольная связка еще не HITL.

**Шаг 3 — интеграция и полеты.** Смонтировать авионику и оптику, измерить
ЦМ/рычаги, откалибровать камеру и выносной компас. Выполнить наземные
проверки/пробежки и ручные полеты. GPS сначала использовать как независимый
регистратор, исключив его данные из проверяемой навигации; затем —
автономный полет без GPS после проверки ручного перехвата и аварийных режимов.

## 4. Быстрый запуск демонстрации

Ubuntu 24.04 WSL с установленным окружением проекта.
**Выполнить в трех отдельных терминалах**; первый включает подготовку и армирование:

~~~bash
cd /home/nikol/autopilot && bash src/glider_visual_nav/tools/demo.sh flight 90
cd /home/nikol/autopilot && bash src/glider_visual_nav/tools/demo.sh gui
cd /home/nikol/autopilot && bash src/glider_visual_nav/tools/demo.sh dashboard
~~~

После теста сервер и узлы останавливаются. Для повторного показа снова
выполнить первую команду. Не запускать demo.sh start одновременно с flight.
Демонстрация показывает текущую симуляционную телеметрию, не запись видео.
