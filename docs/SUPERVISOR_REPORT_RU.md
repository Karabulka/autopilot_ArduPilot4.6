# Навигация планера без GPS: статус проекта
**12 ноября 2026 года | ArduPlane 4.6.3 + Gazebo Harmonic + ROS 2 Jazzy**

## 1. Практический результат

| Компонент | Что реализовано |
|---|---|
| Симуляционный стенд | Управляемый полет glider_visual в GUIDED, штатное армирование. GPS1_TYPE=0, GPS2_TYPE=0; EKF3 без GPS. |
| Оптическая навигация | Собственный конвейер OpenCV: Shi-Tomasi, cornerSubPix, пирамидальный Lucas-Kanade, forward-backward, RANSAC, МНК с весами Хьюбера. Компенсация вращения, наклона и рычага камеры. |
| Курс и управление | Магнитный курс с компенсацией крена/тангажа и склонения; счисление пути в ENU; LOS по путевым точкам. |
| Модель и датчики | LiftDrag-модель планера; надирная камера 640×480, 30 Гц; IMU, барометр, магнитометр. |
| Интерфейсы | MAVLink 2: OPTICAL_FLOW, VISION_SPEED_ESTIMATE, VISION_POSITION_ESTIMATE, SET_ATTITUDE_TARGET. Нативные ROS 2 топики. |
| Дашборд | Карта, видеопоток, оценка пути против эталона Gazebo; 8 графиков наведения и точности, запись журналов. Векторы потока на видео пока не наложены. |

**Итог: flight.passed=true; accuracy.passed=true; 27/27 проверок colcon без ошибок.**
Задержка около 1,25 с устранена дренированием внутренней очереди UART SITL.

## Границы доказанного

| Ограничение | Что необходимо учитывать |
|---|---|
| Условия приемки | Плоская текстурированная поверхность, штиль, INERTIAL_SOURCE=direct. Истина Gazebo поступает только оценщику. |
| Идеальные датчики | Ориентация IMU идеализирована; 7,5 мм по высоте не характеризуют реальный барометр. |
| Сравнительный режим | INERTIAL_SOURCE=mavlink не принят по точности: фаза/фильтрация ATTITUDE и обратная связь ExternalNav. Единственная причина остаточной ошибки не доказана. |
| Курс автопилота | Yaw ATTITUDE: RMSE около 4,35°. Наш магнитный курс - отдельная величина. |
| Область вывода | 90 с не доказывают отсутствие длительного дрейфа, точность любого маршрута или готовность аппаратуры. Задержки по /clock не гарантируют hard real-time. |

Источник: docs/results/acceptance_20261112.json и XML результатов colcon.

## 2. Статус выполнения задач

| Задача | Статус | Подтверждение / остаток |
|---|---|---|
| Переход на ArduPilot 4.6 | Выполнено в SITL | Plane 4.6.3; патчи EKF3, UART/FDM/часов; GUIDED и штатное армирование. |
| Изучение Optical Flow | Обзор готов | Сравнение алгоритмов и вычислительного бюджета. OpenFlow как SDN-протокол к задаче не относится. |
| Модуль потока и точность | Приемка пройдена | 0,113 / 0,132 м/с в идеальном SITL; аппаратура не испытана. |
| Планер в Gazebo | Интегрирован | glider_visual работает; поляры реального борта еще не идентифицированы. |
| MAVLink + ROS 2 | Работает в SITL | Управление, ExternalNav, сенсоры, одометрия и дашборд; физический UART не испытан. |
| Бортовое оборудование | Подобрано, не закуплено | Pi 5; Matek H743-WING V3 / Pixhawk 6C; OV9281 / IMX296; RM3100, Пито, питание, UART 921600 бод. |
| Дальномер и носитель | Есть BOM и компоновка | Ranger 2400 757-9 PNP; TFmini-S - ближний канал, SF20/C - кандидат для 30-60 м. |

**Модель не является цифровым двойником:** glider_visual - 3,2 м / 1,6 кг;
Ranger - 2,4 м. Геометрию, массу, ЦМ, инерцию и поляры реальной сборки нужно измерить.

## 3. Следующие шаги

| Этап | Основные работы | Критерий завершения |
|---|---|---|
| 1. Усложнение SITL | Ветер, переменный рельеф, лазерный AGL, отказы датчиков; уточнение поляр. Снос оценивать по путевой скорости, курсу и Пито с учетом скольжения. | Повторная приемка в усложненных условиях. Один Пито угол сноса не определяет. |
| 2. Настольный стенд, затем HITL | Утвердить BOM; собрать Pi 5 + Matek + Global Shutter камеру. Проверить питание, timestamps, UART 921600, FPS и задержки ARM Cortex-A76. | Измерения на реальной аппаратуре; затем подключение контроллера к симуляции для HITL. |
| 3. Борт и полеты | Монтаж, ЦМ/рычаги, калибровка камеры и компаса; наземные проверки, ручной облет. GPS - только независимый регистратор. | Автономный полет без GPS после проверки ручного перехвата и аварийных режимов. |

## 4. Демонстрация: три команды

**Ubuntu 24.04 WSL; выполнить в трех отдельных терминалах.**

~~~bash
cd /home/nikol/autopilot && bash src/glider_visual_nav/tools/demo.sh flight 90
cd /home/nikol/autopilot && bash src/glider_visual_nav/tools/demo.sh gui
cd /home/nikol/autopilot && bash src/glider_visual_nav/tools/demo.sh dashboard
~~~

Первый запуск включает подготовку и армирование. После теста сервер и узлы
останавливаются; для повтора снова выполнить первую команду.
Не запускать demo.sh start одновременно с flight.

Репозиторий: [github.com/Karabulka/autopilot_ArduPilot4.6](https://github.com/Karabulka/autopilot_ArduPilot4.6).
