# Результаты испытаний — 4 ноября 2026

## Длительная навигация PX4

Существующий прогон завершен: 1200 с симуляции, 36 246 сопоставленных
отсчетов, 14 288,04 м пути. Конечное расхождение XY 121,89 м (0,853%).
RMSE скоростей FLU 0,179 / 0,106 м/с, RMSE магнитного курса 1,642°
(на крене 1,732°), RMSE поперечного отклонения 30,21 м.
Высота корпуса 38,95–41,74 м; максимальный пропуск навигации 0,528 с.

Ориентир около 100 м за 20 минут не достигнут. Прогон доказывает
работу контура, но не снижение дрейфа. Второй 20-минутный прогон
не запускался. Для выявления причин нужны анализ знака ошибок по
участкам, доля кадров без полного покрытия IMU и отдельные
испытания зеркальных маршрутов. Абсолютная поправка XY не реализована.

  не оставлены в профиле запуска. Предполетные проверки не отключались.

  не подтверждены. Модель текущего стенда — безмоторная.

## Дополнительная проверка: ArduPilot как основной запуск, 5 ноября

Обычные demo.sh start/gui/dashboard/status/stop теперь используют ArduPlane,
ROS_DOMAIN_ID=67 и GZ_PARTITION=glider_arduplane. PX4 доступен явно через
demo.sh px4. BUILD_PX4_INTERFACE по умолчанию OFF. Проверен реальный цикл
start → status → stop: ARDUPLANE_MONITOR и одометрия на креплении
X≈0, Y≈0, Z≈145,24 м. start не выполняет автоматическое армирование.

Кадры imu_aided ожидают полного покрытия интервала буфером IMU, включая
imu_camera_time_offset. Очередь ограничена шестью кадрами; при переполнении
или просрочке пара сбрасывается. Добавлен тест двух границ интервала.
Изолированная сборка с BUILD_PX4_INTERFACE=OFF и colcon test-result:
26 тестов, 0 ошибок, 0 отказов, 0 пропусков.

Контрольный запуск после изменения: штатное arming и GUIDED подтверждены,
60,0 с после освобождения, 60,0 с движения в воздухе по суммарному счетчику,
минимальная/финальная высота 70,456 м; пиковая скорость 16,591 м/с.
2486 кадров, 2482 IMU, 8197 магнитных, 1775 барометрических отсчетов,
2323 Odometry; 3289 активных отсчетов интерфейса. Строгая проверка начала
движения в заданном двухсекундном окне не пройдена: passed=false сохранен.
Это не приемка точности маршрута.
[Сырые агрегаты](results/arduplane_coverage_60s.json).
