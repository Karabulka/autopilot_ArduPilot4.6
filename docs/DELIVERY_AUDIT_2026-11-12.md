## Что доступно на рабочем столе

ОТКРЫТЬ.html — индекс документов и ссылок на реальные файлы, а не архив
только с описанием. Раздел artifacts содержит:

- patches/: все шесть патчей, включая sitl_uart_drain_frames.patch
  и fdm_drain_latest.patch.
- results/: четыре исходных JSON приемки.
- tests/source/: исходники тестов; tests/results/: семь XML с 27 проверками.
- tests/acceptance_test_result.log: исходный вывод colcon test-result.
- glider_visual_nav_sources.zip: весь исходный пакет, выбранные документы,
  JSON приемки, README и AGENTS, без Git-данных, бинарников и сырых журналов.
- manifest.json: SHA256 файлов и исходников, публикационная ревизия.

Экспорт воспроизводится командой:
python3 src/glider_visual_nav/tools/export_documents.py DESTINATION

После коммита экспорт обновляется повторно, чтобы индекс и манифест
показывали итоговую опубликованную ревизию. SHA256 проверяются отдельно.
Материалы не являются установленным ROS/Gazebo-дистрибутивом Windows:
проект запускается в Ubuntu WSL по инструкции START_ARDUPILOT_RU.
