# Диагностика yaw и полет

На неподвижном стенде после согласования поля: ATTITUDE.yaw=1,56804 рад,
yaw ENU навигации=0,002713 рад, yaw NED ExternalNav=1,56808 рад.
Разность ArduPlane/ExternalNav около 0,0023°. RAW_IMU [49,-245,420] мГс.
Матрицы T и S корректны; эти значения относятся к периоду до полета.

JSON SITL штатно использует WMM, а не поле Gazebo. В испытательном патче
поле NED зафиксировано: [245,01664446;49,66733270;420] мГс, как в мире.
COMPASS_AUTODEC=0, COMPASS_DEC=0,2 рад, COMPASS_ORIENT=0.
Меняется физическое окружение датчика, эталон позиции не используется.

Настоящая причина блокера: InitialiseFilterBootstrap в
AP_NavEKF3/AP_NavEKF3_core.cpp безусловно требует GPS fix для Plane.
С выключенным GPS EKF3 оставался неинициализированным, и проверка
сравнивала его начальный yaw с рабочим AHRS.
Патч исключает это требование только при явно выбранном SourceXY::EXTNAV.
Остальные источники сохраняют требование GPS. Проверки армирования,
здоровья EKF и компаса оставлены. Это Plane 4.6.3 с локальными патчами,
а не подтверждение возможности полета на штатном бинарнике без изменений.

Ноль Z ExternalNav согласован с барометрическим нулем на старте:
позиция Z относительно начального положения, высота origin 145,25 м,
Home на земле. Дашборд сохраняет высоту корпуса над плоскостью.
При свежем RAW_IMU для деротации используется физический gyro вместо
скорости с коррекцией AHRS; резерв — ATTITUDE rates. Обе величины
переводятся из FRD в FLU.

Штатное армирование прошло (ACK 400 result=0). После освобождения
выполнен 90-секундный интервал, около 87,9 с непрерывно в воздухе;
финальная высота 12,9 м. Строгий smoke-test оставлен passed=false:
первый квалифицированный воздушный отсчет оказался позже допуска 2 с.

Качество маршрута не пройдено. На отдельном окне дашборда RMSE курса
15,5°, e⊥ 53,6 м, ошибки скорости велики. Это не метрики полного
90-секундного интервала. Исходные агрегаты и scope окна сохранены в
results/arduplane_guided_2026-11-05.json.

imu_camera_time_offset оставлен 0: на фоне больших ошибок ориентации
нельзя заявлять выигрыш от произвольной задержки 10–25 мс.
Патчи применяет build_arduplane.sh; контроль GPS-зависимого поведения
для остальных источников не менялся.
