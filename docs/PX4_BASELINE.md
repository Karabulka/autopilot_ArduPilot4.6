# Сохраненный контур PX4

Контрольный контур использует исходный checkout PX4 на базе
4a5eabb61e3c3baf96e7528ed6d4027d853f9534 и моделей Gazebo на базе
6cfb3e362e1424caccb7363dca7e63484e44d188. Это отдельный проверенный
стенд, а не часть сборки ArduPlane. Публикация содержит исходники
адаптера PX4, отдельную копию измененных моделей/миров и патч интеграции.

Для воспроизведения на чистой базе: инициализировать ее подмодули,
применить compat/px4/changes.patch к исходному дереву PX4, скопировать
дерево compat/px4/overlay и целевые модели/миры из Tools/simulation/gz
поверх соответствующих каталогов. Использовать лицензии upstream.
Собрать px4_sitl_default, подготовить совпадающие px4_msgs и XRCE Agent
через src/glider_visual_nav/tools/prepare_px4_dependencies.sh, собрать
пакет с BUILD_PX4_INTERFACE=ON. Затем использовать demo.sh start, status,
dashboard, gui, focus и fly. Вариант ArduPlane использует UDP MAVLink,
позволяет собрать пакет с BUILD_PX4_INTERFACE=OFF и не требует PX4.

Полный исходный PX4 и бинарные артефакты не включены в отдельную публикацию.
У эталонных JSON указаны режим и продолжительность; результаты разных
моделей не смешиваются. Данные Gazebo не используются для навигации.
